Chuyển Đổi Marker Tự Động

Nạp đề thi Word truyền thống (Câu 1., Câu 1:, 1) và đáp án A, B, C, D... gạch chân). Tự động phân tích và tạo file Word mới đã gắn sẵn chuẩn marker __QUESTION__, __D__, __S__.

  • Nhận diện Câu 1., Câu 1:, Câu 1), 1)
  • Đáp án gạch chân → __D__, còn lại → __S__
  • Tự động tách đáp án thẳng hàng 2 - 4 cột
  • Tải file Word (.docx) sạch đẹp về máy

Trộn Đề Thi Trắc Nghiệm

Nạp file Word đã gắn marker hoặc dán trực tiếp. Hoán vị câu hỏi, hoán vị đáp án, chia nhóm/phần linh hoạt, xuất file đề thi đẹp chuẩn cùng bảng đáp án ma trận.

  • Xuất N mã đề tự động hoán vị theo nhóm
  • Tự động thêm tiêu đề PHẦN I, II, III...
  • Bảng đáp án ma trận tổng hợp chi tiết
  • Tải file Word từng mã hoặc trọn gói ZIP

Hướng Dẫn Quy Tắc Marker

Xem tài liệu hướng dẫn chi tiết về cú pháp marker (__G__, __QUESTION__, __D__, __S__, __D#__), quy tắc nhóm và cách tạo đề chuẩn xác.

  • Bảng tra cứu cú pháp marker đầy đủ nhất
  • Mẫu đề thi chuẩn tải về thực hành
  • Hướng dẫn xử lý hình ảnh In Line with Text
  • Mẹo tránh các lỗi định dạng thường gặp
